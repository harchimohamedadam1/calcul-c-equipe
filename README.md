# calcul-c-equipe

## Description

Projet collaboratif en langage C réalisé dans le cadre du TP Git/GitHub.

Ce projet permet de pratiquer le travail collaboratif avec Git et GitHub.

## Fonctionnalités

- Affichage du message « Projet collaboratif ».
- Calcul du produit de deux nombres entiers.
- Calcul de la moyenne de deux nombres entiers.
